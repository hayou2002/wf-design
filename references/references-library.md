## 本地优先

| 资源 | 适合参考 | 呈现方式 |
| --- | --- | --- |
| oil-art-landing 内置预览 | 艺术感品牌官网、多屏落地页 | 用 oil-ui-pro 生成 3 方向对比页 |

## GitHub 搜索

先按产物和核心元素搜索，再检查仓库是否有 README 截图、项目官网、在线 Demo、Storybook 或视频。候选应有可视材料，复用时另查许可证、技术栈、最近维护与付费限制。

聚合目录只作为搜索入口，不直接把仓库列表交给用户。可从 https://github.com/birobirobiro/awesome-shadcn-ui 等目录继续定位具体项目，最终呈现具体设计的预览。
